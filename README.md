# Fixmate – Home Service Marketplace 🏠

Fixmate is a full-stack home service marketplace application designed to connect customers with skilled service providers. It allows users to find and access essential home services conveniently at their doorstep.

The platform provides services such as plumbing, electrical work, carpentry, cleaning, painting, AC repair, and appliance repair.

## 🚀 Features

### 👤 User Authentication
- User registration and login.
- Token-based authentication using JWT.
- Password encryption using bcrypt.
- Role-based navigation.

### 🔧 Service Categories
- Electrician
- Plumber
- Carpenter
- Painter
- AC Repair
- Appliance Repair
- Cleaning Services

### 🧑‍🔧 Service Providers
- Explore available service providers.
- Select required services.
- Choose suitable working hours.
- Access service information.

### 📅 Booking Management
- Booking API integration.
- Service booking management.
- Customer and provider functionality.

### ⭐ Additional Features
- Review API integration.
- Admin dashboard.
- Provider dashboard.
- Responsive user interface.
- REST API architecture.
